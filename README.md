# 本地知识智能助手

使用 **LangChain + ChromaDB + Streamlit + 阿里云百炼**，实现可直接聊天、连续追问，并优先参考本地资料的智能助手；提供 **FastAPI** 接口，语音转文字可切换为实验室服务。

## 已实现

- 客服 FAQ Demo：标准问题或相似问法精确匹配优先，其次使用向量与 BM25 中文关键词混合检索；语义分低于 70 分时走原来的文档 RAG 与普通聊天。
- 顶部“FAQ 管理”独立页面支持加载客服示例、手动添加、导入 JSON、查看删除、保存匹配设置和测试匹配；FAQ 保存到本机，重启保留。
- 上传 TXT、Markdown、文字型 PDF；文本支持 UTF-8、UTF-8 BOM 和 GB18030。
- LangChain 将文档切分成约 800 字符的片段，相邻片段重叠 120 字符。
- 百炼 `text-embedding-v4` 将文本转换成向量，每批最多 10 段。
- ChromaDB 在本机保存向量、原文片段及来源，重启后继续使用。
- 在候选资料上计算真实余弦相关度，只将达到门槛的前 4 段交给百炼 `qwen-plus`。默认门槛为 0.35，可在侧栏调整。
- 有相关资料时优先引用本地内容，并允许模型补充常识；补充段落要求标明“模型补充”，本地引用用 `[1]` 等编号。
- 空知识库或没有相关资料时，直接由模型正常聊天，不限制输入，也不展示无关原文。
- 支持连续追问：保留最近 12 条有效对话，总历史上限 18,000 字符；有资料时结合上文改写检索问题。
- 向量查询或资料检索失败时，尝试由回答模型继续对话，不会将无关资料冒充引用。
- 回答按模型实际生成的文本流逐段显示；中断时关闭模型流，不把半截回答写入网页对话历史。
- 聊天输入栏内置麦克风，结束录音后自动转写并填回同一输入栏，可直接修改后发送。默认使用百炼 `qwen3-asr-flash`，可切换为实验室 HTTP ASR。
- FastAPI 提供普通聊天、SSE 流式聊天、文档上传、知识库状态和语音转写接口，与网页共用 RAG 核心。
- 相同文件名且内容相同的重复上传会跳过，不重复调用向量接口。

这里使用 `langchain-openai` 适配百炼的 **OpenAI 兼容协议**；实际聊天和向量请求均发送到配置的百炼地址，使用百炼 API Key。

相关度通过问题向量与原文向量计算，不把“检索总会返回几个结果”当作资料相关。当前取最多 `max(20, top_k × 4)` 个候选并重新排序，兼容已有 Chroma 集合；升级无需重新上传现有资料。0.35 是用示例问题校验的经验门槛，不代表 35% 的正确率，应随自己的文档调整。[Chroma 距离说明](https://docs.trychroma.com/docs/collections/configure)

## 启动（Windows PowerShell）

在本项目目录中运行。当前项目使用 Python 3.13。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

如果虚拟环境和依赖已经安装，直接执行最后一条即可；也可以执行 `./start.ps1`。

浏览器打开 <http://127.0.0.1:8501>。

接口服务单独启动：

```powershell
.\.venv\Scripts\python.exe -m uvicorn api:app --host 127.0.0.1 --port 8001
```

也可运行 `./start_api.ps1`。交互接口文档位于 <http://127.0.0.1:8001/docs>，完整请求示例见 [API.md](API.md)。两个服务可独立运行；网页直接使用共享核心，不要求先启动 HTTP 接口。

安卓设备局域网联调：运行 `./start_api.ps1 -ListenAddress <电脑的局域网IPv4>`，按 [局域网联调说明](LAN_DEBUG.md) 检查网络与防火墙，再通过设备浏览器验证 `/health`。

## 配置百炼

**方式一：** 启动后，在网页侧栏填写 API Key。它只保存在当前运行会话中，不会写入项目文件。

**方式二：** 复制配置示例：

```powershell
Copy-Item .env.example .env
```

编辑 `.env`：

```dotenv
DASHSCOPE_API_KEY=在本地填入你的百炼APIKey
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
CHAT_MODEL=qwen-plus
EMBEDDING_MODEL=text-embedding-v4
```

`.env`、虚拟环境和 `data/` 已加入 `.gitignore`。修改 `.env` 后请重启应用；网页侧栏也可以修改模型和调用地址。

默认地址对应北京地域。**API Key 与调用地址必须属于同一地域**，模型也需在该地域可用。当前官方推荐使用控制台中的业务空间专属地址，例如：

```text
https://你的业务空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
```

旧北京地址仍受支持，因此最小版保留为默认值。新加坡等其他地域请使用控制台给出的对应地址。[百炼官方兼容接口说明](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)

向量接口设置了 `check_embedding_ctx_length=False`，直接发送文本，避免适配器把输入转换为 OpenAI 的 token ID；同时显式请求浮点向量，并限制每批 10 段。[百炼向量接口限制](https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api)、[LangChain 实现说明](https://github.com/langchain-ai/langchain/blob/master/libs/partners/openai/langchain_openai/embeddings/base.py)

## 第一次体验

1. 填入百炼 API Key。
2. 不上传文档也可问“什么是机器学习？”，再追问“给我一个生活中的例子”。
3. 上传项目中的 `examples/knowledge.md`，点击“加入知识库”。
4. 询问“读书会什么时候举行？顺便给我两条参加讨论的建议”，核对本地引用与模型补充。
5. 追问“那报名截止时间呢？”，检查能否结合上一轮理解主题。
6. 再问“马化腾是谁？”，应由模型正常回答，不强行引用读书会资料。

API Key 未配置时可以启动界面；实际建库和问答需要有效 Key，也会产生百炼模型调用。

## 系统提示词与助手身份

系统提示词集中在 `prompts.py`，按 Role（角色）、Task（任务）、Rules（规则）、Input（输入约定）组织。普通聊天、知识问答、流式输出和内部检索改写都通过真实的 `system` 消息预置任务规则，消息顺序为系统提示词、有效历史、当前问题；网页和 FastAPI 使用同一套 RAG 核心。

助手的应用名称为“本地知识智能助手”，询问身份时以此介绍自身能力，普通回答不重复自我介绍。明确询问底层模型时，按服务端当前配置如实说明阿里云百炼与模型标识，不把应用名称冒充成独立训练的模型。历史中的旧身份和文档内的角色指令不能覆盖当前系统规则。

有资料时继续区分“资料参考”和“模型补充”，无资料时正常聊天且不虚构引用。FAQ 命中直接返回标准答案，不为加入提示词而额外调用模型。

后续修改应用名称或回答规则，可编辑 `prompts.py` 并递增 `PROMPT_VERSION`。网页下一次运行会重建服务并保留对话，FastAPI 需重启后生效。提示词不能保证模型绝不偏离规则；身份、资料引用和实时能力仍需用实际问题检查。

## 客服 FAQ Demo

点击顶部“FAQ 管理”，或打开 <http://127.0.0.1:8501/faq>。页面包含“问答管理”“匹配设置”“匹配测试”三个标签页，所有 FAQ 操作都在主内容区。切回“聊天”会保留当前连接与对话记录。

在“问答管理”点击“加载客服示例”，然后回到聊天直接问“怎么退款”“退款多久到账”“怎么查快递”或“转人工”。命中时页面显示“FAQ 标准答案”，直接返回保存的答案，不调用回答模型。重复加载相同示例不会新增重复条目；示例使用虚构商城流程，不连接真实订单、物流或客服。

可以在同一个面板填写标准问题、标准答案和相似问法（每行一个），点击“添加 FAQ”。也可上传项目中的 `examples/faq.json`，或使用同样结构的 UTF-8 JSON 文件：

```json
[
  {
    "question": "如何联系人工客服？",
    "answer": "进入帮助与客服页面，选择联系人工客服。",
    "aliases": ["转人工", "我要找人工客服"]
  }
]
```

单次导入最多 1 MiB、500 条；标准问题最多 4000 字符，标准答案最多 12000 字符，相似问法最多 20 个、每个最多 4000 字符。重复内容跳过；相同问题答案不同或问法属于其他条目时提示冲突，整次导入回滚。Demo 修改内容时，先删除原条目，再添加新内容。

已有问答可直接“补充相似问法”，保存时保留原编号、答案和已有问法。例如把“退款在哪里”补到“如何申请退款”，明确它询问退款入口，避免与“退款多久到账”混淆；不需要放宽全局门槛。标准答案本身的修改仍采用先删除再添加。

FAQ 独立模块为 `faq.py`，使用 Python 自带 SQLite 保存正式问答，使用现有 ChromaDB 和百炼向量模型保存独立检索索引。新增轻量依赖 `jieba` 和 `rank-bm25`，不新增数据库服务。数据位于当前 Chroma 目录内的 `faq.sqlite3`，不会混入文档分块。精确匹配无需向量请求；首次非精确匹配会为缺失的标准问题和相似问法创建向量，后续复用。网页和 FastAPI 可看到彼此新增或删除的 FAQ。

“匹配设置”默认语义门槛为 **70 分（0.70）**。保存后立即写入本机 SQLite，网页和 FastAPI 的后续查询都会采用，无需重启；原有聊天记录和向量不受影响。`.env` 的 `FAQ_MATCH_THRESHOLD` / `FAQ_MIN_MARGIN` 仅在尚未保存页面设置时作为默认值。

非精确匹配先合并向量与关键词候选，再按“80% 余弦分 + 20% 相对 BM25 分”排序；没有关键词命中时保留原来的余弦排序。原始余弦分必须达到门槛，BM25 不会把低于 70 的候选抬成命中；第一、第二条 FAQ 的混合分差仍需达到“候选领先分”（默认 8 分）。分数不是正确率，候选接近时继续 RAG。中文分词使用 jieba 搜索模式，移除常见虚词，保留否定与数字；BM25 使用 BM25Plus(delta=0) 适配小型 FAQ 库。[jieba 说明](https://github.com/fxsjy/jieba)、[BM25 实现](https://github.com/dorianbrown/rank_bm25)

在“匹配测试”输入问题，可查看命中或回退原因、候选语义分、BM25 原始分和混合分；测试只查询 FAQ，不生成模型回答。BM25 分数不是百分比。更换向量模型时保留正式 FAQ，语义索引按新模型重新生成。

这是面向客服的单轮标准问答 Demo；复杂多轮澄清、审核、分类、权限和医疗规则后续再加。FAQ 没有命中时，仍保留现有聊天补充能力；FAQ 检索故障也继续尝试原来的问答流程。

## 语音输入与实验室模型

点击聊天输入栏右侧的麦克风开始说话，点击同一位置的完成按钮（✓）结束录音。应用自动识别语音，并将文字填回这个输入栏；已有草稿会保留，识别文字追加在后面。你可以直接修改，确认后点击发送箭头或按 Enter，回答同样使用流式输出；Shift+Enter 换行。录音时也可点击取消按钮放弃本次录音。

语音识别不会自动发送问题，不再需要展开面板或手动点击“识别”。浏览器第一次录音时需要你允许访问麦克风；识别失败仍可直接打字。单次消息最多 4000 字符，较长的识别结果会完整保留在输入栏，删减后即可发送。

默认配置不需要新增 Key，复用现有百炼连接：

```dotenv
ASR_PROVIDER=bailian
ASR_MODEL=qwen3-asr-flash
```

若 ASR 使用独立 Key 或地域地址，可设置 `ASR_API_KEY` / `ASR_BASE_URL`。优先级为独立 ASR 配置、网页当前连接、聊天环境配置。默认录音是 16 kHz WAV。录音在内存中传给 ASR，不加入知识库；使用百炼时音频会发送至百炼。

实验室模型部署后，将 `.env` 改为以下配置并重启服务：

```dotenv
ASR_PROVIDER=http
ASR_HTTP_URL=http://127.0.0.1:9000/transcribe
# 如果实验室服务需要 Bearer Token，再设置 ASR_HTTP_API_KEY。
```

实验室接口接收 `multipart/form-data` 的 `file` 音频字段，并返回 `{"text": "识别出的文字"}`。如果以后直接加载本地模型，也可以实现 `speech.SpeechToText.transcribe()` 并在工厂注册；网页、RAG 和 FastAPI 无需依赖模型内部实现。

单次音频原文件最多 10 MiB，WAV 最长 5 分钟；百炼另要求 Base64 编码后不超过 10 MiB，因此原音频实际约需小于 7.5 MiB。当前百炼适配器支持 WAV、MP3、FLAC、OGG、WebM；M4A 请转换为 WAV 或 MP3。非 WAV 文件的时长由语音服务校验。[百炼 ASR 官方协议](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)

## 常见问题

- **需要先上传才能聊天吗？** 不需要。模型配置有效后即可聊天；知识库为 0 段或上传失败不会禁用输入框。选中文件后点击“加入知识库”，才会保存为本地参考资料。
- **为什么没查资料也能回答？** 没有达到相关度门槛的资料时，由模型知识回答，页面标注“模型回答”，不展示无关引用。
- **能回答今天天气吗？** 当前尚未接入天气或联网工具，模型兜底使用的是已有知识。它应说明无法实时查询，不能编造天气、行情或最新新闻。
- **应用的网络访问被系统阻止：** 请在本机 PowerShell 中执行 `./start.ps1`，让应用在能够访问百炼的环境中运行。仅填写正确 API Key 不能解决进程没有联网权限的问题。
- **启动提示端口被占用：** 新服务没有启动成功，浏览器可能仍在访问旧服务。先关闭此前启动本项目的服务，再重新启动；刷新页面后重试上传。独立测试脚本调用成功，并不代表网页服务的网络访问也正常。

## 当前范围

- 面向单人本地使用，应用默认仅监听 `127.0.0.1`。
- 单个文件最多 20 MB。扫描 PDF 的 OCR、Word、表格和网页抓取暂未加入。
- 多轮记忆限于当前会话的最近 12 条有效消息；有库时追问改写会多调用一次模型。
- 流式输出从检索和追问改写结束后开始；语音转文字目前是录音结束后的整段识别，尚未实现边录音边转写。
- FastAPI 为本机单人服务，所有请求共用一个本地知识库；HTTP 客户端负责在请求中传入对话历史，服务端不保存会话。
- 同名但内容不同的文件视为不同版本，都会保留。当前没有文档删除或覆盖操作。
- 更换向量模型、调用地址或分块参数会使用不同集合，需要重新上传；原集合仍保留。更换回答模型不需要重新建库。
- 对话记录只在当前网页会话中保存，已加入的知识库保存在本机。
- 调整相关度门槛或回答模型保留当前对话；切换向量模型或调用地址后清空当前对话，避免混用不同知识库的资料。
- 原文片段会保存在 ChromaDB；建库时发送文本片段到百炼，问答时发送问题、有限历史及相关资料。
- 模型补充来自训练知识，不代表实时核实。对于资料中没有的私人信息或具体活动细节，仍要求模型说明不确定，不编造。
- 相关度是经验性筛选；较大知识库的候选检索仍是近似检索。引用与补充的划分依赖模型遵循提示词。

后续可逐步加入联网工具、专用重排模型和小型评估集；技术链无需替换。
